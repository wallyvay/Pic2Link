Pic2Link is a native macOS menu bar client for uploading a user's own images and files directly to storage they configure. It has no Pic2Link account, subscriptions, in-app purchases, developer upload server, advertising, or analytics. The paid app does not include cloud storage; any service costs are charged separately by the user's chosen provider. Credentials are kept in macOS Keychain.

The app is a menu bar utility and intentionally does not show a Dock icon. Click its image/link menu bar icon to open the upload panel and Settings. Add a storage profile using the + menu in Settings (S3-compatible services, WebDAV, or an image host). Select that profile, choose a file or drag an image onto the menu bar, and the resulting public link is copied after upload. The configured public URL prefix must correspond to the provider's read access configuration. Pic2Link does not change bucket permissions.

Optional features are available in the menu and Settings: Add Text Before Upload, image resizing, Live Photo to GIF, and Markdown Links. The text draft opens beneath the menu bar icon. Command-Return confirms it, copies nonblank caption text, and uploads; a blank draft skips text composition. Text rendering and resizing run locally without modifying source files. Caption text becomes Markdown alternative text when Markdown Links is enabled. Clicking an upload history item copies its link with a success sound.

Command-Shift-U reads only the user's current selection in the foreground Photos app. This is separate from Command-U, which uploads the clipboard image. Photos access uses its com.apple.Photos.library.read scripting access group and PhotoKit, with system permissions requested when needed. The app does not use UI scripting, simulated Copy, screen capture, or scan other applications.

In response to Guideline 2.4.5(i), the revised Mac App Store build removes the temporary Apple Events exception entirely. It does not send Apple Events to Finder. Upload Finder files by dragging them onto the menu bar icon, copying them to the clipboard and using Command-U, or choosing a file with the system file picker. Command-Shift-U in Finder displays guidance to use these alternatives instead.

Review configuration must be appended securely before these notes are uploaded. The release lane requires a verified, isolated review account; no personal or production credentials are included in the app or source repository.

Launch at login uses SMAppService. This Mac App Store build enables App Sandbox and has no LaunchAgents/launchctl fallback. Network requests go directly to the user's configured provider. Only Apple's system networking, Keychain, and CryptoKit are used for TLS and request authentication; no non-exempt encryption is included.
