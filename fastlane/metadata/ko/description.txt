Mac 메뉴 막대에서 이미지와 파일을 업로드하세요. 일반 URL 또는 Markdown 이미지 링크를 복사하고 최근 업로드를 확인할 수 있습니다.

S3 호환 서비스, WebDAV 등 원하는 저장소와 이미지 호스트를 연결하세요. 설정에 서비스 계정과 인증 정보를 입력해야 합니다. 저장소 요금제와 비용은 각 서비스에서 별도로 제공합니다.

클립보드나 드래그 앤 드롭으로 업로드합니다. 사진 앱에서 선택한 사진에는 Command-Shift-U를 사용하세요. 업로드 전에 문구를 자동 배치하고, 메모리에서 크기를 조절하거나 Live Photo를 GIF로 변환할 수 있습니다. 문구를 비우면 합성을 건너뜁니다.

이미지는 Mac에서 처리되며 원본 파일은 변경되지 않습니다. 인증 정보는 macOS 키체인에 저장되고 콘텐츠는 설정한 서비스로 직접 전송됩니다.
